# Release Policy

Every release shall satisfy the following requirements:

* Documentation completed.
* Architecture reviewed.
* Standards approved.
* Related ADRs finalized.
* Repository updated.
* Executive approval obtained.

No release shall be considered complete until all required documentation has been approved.
